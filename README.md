# ESP32-DSP 2-Way Active Crossover

A professional-grade DSP platform built on the ESP32 — a 2-way active crossover with parametric EQ, compressor, limiter, delay, Bluetooth A2DP input, OLED UI, rotary encoder, footswitches, and preset management.

## Features

### DSP Effects
- **4-band Parametric EQ** — Low-shelf, 2× peaking PEQ, high-shelf (biquad IIR, before crossover)
- **1st-order Crossover** — 6 dB/octave low-pass / high-pass, 200–4000 Hz adjustable
- **Per-driver Compressor** — Feed-forward, adjustable threshold/ratio/attack/release
- **Brickwall Limiter** — Per-driver, infinite ratio, fast attack, configurable ceiling
- **Per-driver Delay** — 0–20ms time-alignment for acoustic center matching
- **DC Block** — 20 Hz high-pass to remove DC offset
- **Parameter Smoothing** — All changes glide over 10–20ms to prevent clicks
- **RMS VU Meter** — Real-time level display on the OLED
- **Mute & Bypass** — Toggle via footswitch

### Hardware
- **Bluetooth A2DP** — Receive audio from any phone/computer (44.1 kHz, 16-bit stereo)
- **I2S DAC Output** — Dual CS4344 DACs (woofer + tweeter), independent DMA channels
- **Controls** — 2× ADS1115 ADC (8 pots), rotary encoder + push, 4 footswitches
- **Expression Pedal** — 1/4" TRS jack input on ADC channel
- **OLED Display** — 128×64 SSD1306, 5-page UI with encoder navigation
- **MIDI Input** — 5-pin DIN, UART2 (pin assigned, parser TBD)
- **Presets** — 8 user presets stored in NVS flash, auto-load on boot

### Software
- **Dual-core FreeRTOS** — DSP on Core 1 (priority 5), UI on Core 0 (priority 2)
- **Ring Buffer** — 8 KB audio buffer decouples BT callback from DSP task
- **Mutex-protected Parameters** — Glitch-free parameter updates
- **Build Stats** — RAM 12.7% (41KB/327KB), Flash 74.8% (1.17MB/1.5MB) on 4MB chip

## Building & Flashing

### Prerequisites
- [PlatformIO IDE](https://platformio.org/install) (VS Code extension) or `pio` CLI
- USB cable for the ESP32

### Build
```bash
# Build for ESP32
pio run -e esp32dev

# Build and upload
pio run -t upload -e esp32dev

# Upload + monitor serial
pio run -t upload -t monitor -e esp32dev
```

Baud rate: **115200**. On boot you'll see:

## DSP Signal Chain

```
┌──────────────────────────────────────────────────────────────────────┐
│                        DSP PROCESSING CHAIN                          │
│                                                                      │
│  Phone ──BT A2DP──► Ring Buffer ──► DSP Task (Core 1)                │
│                                                                      │
│  Per sample:                                                         │
│                                                                      │
│  Raw PCM (16-bit stereo)                                             │
│    │                                                                 │
│    ▼                                                                 │
│  ┌─────────────┐                                                     │
│  │  DC Block   │ 1st-order HPF @ 20 Hz                               │
│  └──────┬──────┘                                                     │
│         ▼                                                            │
│  ┌─────────────┐                                                     │
│  │  Parametric │ 4-band biquad IIR (Direct-Form-II Transposed)       │
│  │  EQ (×4)    │ Low-shelf, PEQ ×2, High-shelf                      │
│  └──────┬──────┘                                                     │
│         ▼                                                            │
│  ┌─────────────┐                                                     │
│  │  Crossover  │ 1st-order IIR LPF (6 dB/oct)                        │
│  │             │ HPF = signal - LPF                                  │
│  └──┬─────┬──-┘                                                     │
│     │     │                                                          │
│     ▼     ▼                                                          │
│  ┌───────┐ ┌────────┐                                               │
│  │  LOW  │ │  HIGH  │                                                │
│  │ woofer│ │tweeter │                                                │
│  └──┬────┘ └───┬────┘                                               │
│     ▼          ▼                                                     │
│  Compressor  Compressor                                              │
│     ▼          ▼                                                     │
│  Limiter     Limiter                                                 │
│     ▼          ▼                                                     │
│  Delay       Delay                                                   │
│     ▼          ▼                                                     │
│  Gain        Gain                                                    │
│     ▼          ▼                                                     │
│  Clip        Clip                                                    │
│     ▼          ▼                                                     │
│  I2S1        I2S0                                                    │
│  CS4344 #2   CS4344 #1                                               │
│  ─woofer amp─ ─tweeter amp─                                          │
└──────────────────────────────────────────────────────────────────────┘
```

### Signal Flow Details

| Stage | Algorithm | Where | CPU |
|-------|-----------|-------|-----|
| DC Block | 1st-order HPF @ 20 Hz | Pre-crossover | ~1% |
| Parametric EQ | 4× biquad IIR (RBJ cookbook) | Pre-crossover | ~10% |
| Crossover | 1st-order IIR LPF (6 dB/oct) | Mid-chain | ~1% |
| Compressor | Feed-forward peak detector | Per driver | ~8% |
| Limiter | Infinite ratio, fast attack | Per driver | ~5% |
| Delay | Circular buffer (0–20ms) | Per driver | ~2% |
| Gain + Clip | Linear gain + hard clip | Per driver | ~1% |
| **Total** | | | **~33%** |

**All parameters are smoothed** with linear interpolation (factor 0.02 per sample ≈ 10–20ms glide) to prevent audible clicks and zipper noise.

## Hardware Controls

### Rotary Encoder (GPIO 34/35/17)
| Action | Function |
|--------|----------|
| Rotate | Adjust parameter on current page |
| Push | Cycle through display pages (0→1→2→3→4→0) |

**Encoder decoding**: Quadrature state-machine ISR on both channels, 4 ticks per detent.

### Potentiometers via ADS1115 #1 (0x48)
| Channel | Parameter | Range |
|---------|-----------|-------|
| CH0 | Master volume | 0–100% |
| CH1 | Crossover frequency | 200–4000 Hz (linear) |
| CH2 | Low-band gain | 0–2.0× |
| CH3 | High-band gain | 0–2.0× |

### Potentiometers via ADS1115 #2 (0x49) — Optional
| Channel | Parameter | Range |
|---------|-----------|-------|
| CH0 | EQ Band 0 frequency | 20–20,000 Hz (log) |
| CH1 | EQ Band 0 gain | -12 to +12 dB |
| CH2 | EQ Band 1 frequency | 20–20,000 Hz (log) |
| CH3 | EQ Band 1 gain / Expression pedal | -12 to +12 dB |

### Footswitches (GPIO 32/33/36/39)
| Switch | GPIO | Function |
|--------|------|----------|
| FS1 | 32 | Preset next |
| FS2 | 33 | Preset previous |
| FS3 | 36 | Mute toggle |
| FS4 | 39 | DSP bypass toggle |

**All buttons**: Active-low, internal pull-ups, ISR-driven with 150ms debounce.

## Preset System

8 presets stored in ESP32 NVS (Non-Volatile Storage) flash. Each preset saves the complete `dsp_params_t` state including all EQ bands, compressor/limiter settings, delay times, mute/bypass state, and an 11-character name.

| Action | Result |
|--------|--------|
| Press FS1 | Load next preset |
| Press FS2 | Load previous preset |
| Power on | Auto-load preset 0 |

**Storage**: NVS key-value store, wear-leveled by ESP32 flash layer (~100k cycles/sector).

## Architecture Summary

### Task Layout
```
Core 0 (UI Task, Priority 2)          Core 1 (DSP Task, Priority 5)
┌─────────────────────────┐           ┌─────────────────────────────┐
│ 1. adc_update_params()  │           │ 1. xRingbufferReceiveUpTo() │
│    - Read 8 ADC channels│           │ 2. xSemaphoreTake(mutex)    │
│    - Process ISR flags  │ ──mutex──►│ 3. Smooth all parameters    │
│    - Map to dsp_params_t│           │ 4. DC Block → EQ │
│ 2. xSemaphoreGive()     │           │ 5. Crossover │
│ 3. ui_update()          │           │ 6. Per-band: Comp→Lim→Delay │
│ 4. vTaskDelay(200ms)   │           │ 7. Gain + Clip              │
└─────────────────────────┘           │ 8. i2s_write (I2S0 + I2S1)  │
                                       └─────────────────────────────┘
```

### Memory Map
| Region | Usage |
|--------|-------|
| Ring buffer | 8 KB (DMA-capable) |
| Raw audio buffer | 512 bytes (DMA) |
| Low/High output buffers | 512 bytes each (DMA) |
| Delay lines | ~7 KB total (4 × 883 samples) |
| EQ state | ~128 bytes |
| Comp/Limiter state | ~64 bytes |
| NVS presets | ~2 KB (8 × 256-byte blobs) |
| Code + libraries | ~1.17 MB Flash |
| Free RAM | ~286 KB |
